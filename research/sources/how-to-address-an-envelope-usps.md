## S1 — USPS FAQ, "Addressing Mailpieces" (primary, official)

URL https://faq.usps.com/articles/Knowledge/Addressing-Mailpieces. Article Number 000008202; no update date.
Verbatim (selected): "Always use a return address - if the letter is undeliverable, it can be returned." "Name and/or "Attention:" line. Print or type delivery address clearly in center of envelope (Use 10, 12, 14 pts for best readability)." "Use all CAPS, spaces between words, no punctuation, and left justify the margin." "Always use applicable directionals in the address (e.g., "N" for north and "S" for south)." "Always use applicable abbreviated locators in address (e.g., APT, ST, AVE)." "Always include applicable RM (Room), FL (Floor), STE (Suite), or APT (Apartment) # on same line as (and after) street address (preferred), or on the line above the street address, not below." "Use two letter state abbreviations in address block." "Use a ZIP+4 ZIP Code (if known) on last line following city and state. Otherwise, use the ZIP Code." "Postage is placed in upper right corner." "This is the barcode area; if you do not have a program that calculates and prints the correct barcode, then leave this area blank."
Return address section: "A return address tells the USPS where the sender wants the mail returned if it is undeliverable and is required on certain types of mail." "For a list of items that that require return addresses, see the Domestic Mail Manual." "Effective December 14, 2023, the Postal Service is no longer accepting items that are shipped domestically and have a foreign return address. Domestic shipments can only have a domestic return address." "A foreign address can only be used when shipping an item internationally, along with the appropriate customs form." Undeliverable domestic items with a foreign return address are handled under "current USPS dead mail procedures."
ZIP: "Not having a ZIP Code on your mail causes unnecessary delay because it will require manual look-up."

## S2 — USPS.com, "How to Send a Letter or Postcard" (primary, official)

URL https://www.usps.com/ship/letters.htm. No update date. Step 2, Address Your Mail: "Write your address (the "return" or "sender" address) in the top left corner. Write the delivery address (the "recipient" address) in the bottom center." Postcards: "write the delivery address in the space it gives you (on the same side you write your message and put the stamp)." Format tips: "Print addresses neatly in capital letters." "Use a pen or permanent marker." "Do not use commas or periods." "Include the ZIP+4 Code whenever possible." Both the return and the delivery address: full name or company name; apartment or suite number; full street address; city, state and ZIP+4, "on separate lines." Special: Puerto Rico urbanization (URB) on 4 lines; Virgin Islands "VI," not "US VI" or "USA VI"; APO/FPO/DPO in another country: no city or country name, but include unit and box numbers if assigned. The page links to "Advanced Tips for Secondary Addresses" and "More Details on Military Addresses" (not read). Postage prices appear elsewhere on the page and are not used.

## S3 — USPS.com address-an-envelope popup (primary, official)

URL https://www.usps.com/send/address-an-envelope-popup.htm. No update date. Placement: "The address, return address and postage should all be on the same side of the package. (If it's improperly addressed, it might get returned to you)." Return Address: "Print or type your address in the upper-left corner on the front of the envelope." Delivery Address: "Print or type clearly the delivery address parallel to the longest side of the envelope." Postage: "Use a stamp or printed postage in the correct amount."

## S4 — USPS video transcript, "How to Address a Package" (primary, official)

URL https://www.usps.com/assets/transcripts/usps-how-to-address-a-package.txt. No update date. "The recipient's address goes in the center." Complete name on line 1; line 2 a post office box or street address; "Additional information, like an apartment, suite, or room number can be added on the same line." "Directional words like north, east, south, west are required, and abbreviations are acceptable." Shortened forms for street, road, drive, avenue can be used, "But writing the words is encouraged." City, state and ZIP plus four; if unknown, use the usps.com Look Up a ZIP Code tool. "It is a requirement to include the sender's address or return address." The return address goes "above and to the left of" the recipient's address, in the same format. "The Postal Service uses highly sophisticated scanners that can decipher most handwriting styles and printed font types." Avoid "red pen or ink that smears"; "If you can, print your labels." Absence tests: no mention of capital letters, caps, commas or periods; no date.

## S5 — USPS.com, "How to Prepare & Send a Package", step 4 (primary, official)

URL https://www.usps.com/ship/packages.htm. No update date. "Please write the address parallel to the longest side of the package, and make sure your return address, the delivery address, and postage will fit on the same side." "If you'll be printing a shipping label (with postage included), you can use that instead of a separate address label. Place all labels on the same side, and don't bend, fold, or overlap labels."
