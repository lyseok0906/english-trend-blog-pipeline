# Content Backlog

Topic candidates for the English trends blog and the stage each one has reached.

Stages: `idea` → `brief` → `evidence` → `draft` → `qa` → `ready` → `published`.
A topic that is rejected stays in the table with stage `rejected` and a reason, so the
same idea is not re-proposed later.

## How a topic enters this table

1. It is a trend or question with real English-language search demand — not a topic
   translated from the Korean economic blog, and not an Excel topic.
2. It is distinct from every other row. Keyword variants of the same question are one
   row, not several.
3. It can be written from sources that can be named and linked.

A topic that fails any of these is recorded as `rejected` with the reason.
