# Blog C — 시험 글 1편 기록 (발행하지 않음) — 2026-10-06

이 문서는 시험 글의 **기록**이다. 영문 원고 본문은 의도적으로 넣지 않았다. 원고는 발행하지 않았고 이 저장소에도 없다.

## 0. 개요

- **시험 글 제목(가제):** What Meta's Muse Changes About Letting AI Act for You
- **주제:** Meta Muse(2026-09-08 발표). 기능 설명보다 "AI에게 일을 맡길 때의 선택 기준"을 다룬 글이다.
- **목적:** "가벼운 디지털 트렌드 글을 계속 만들 수 있는가"를 직접 시험하는 것.
- **상태:** 발행 금지. 사용자의 영어 검토를 거친 뒤에도 발행하지 않았다.

확인하지 못한 것:

- CNBC 기사는 접속이 거부되어(403) 읽지 못했다. 개인정보 주장에 대한 독립적인 비판이나 검증은 하나도 확인하지 못했다. 원고는 이 사실을 그대로 밝히는 문장으로 정리됐다(사용자 검토 반영).
- Meta는 iPhone·Android·웹을, 9to5Mac은 iPhone 앱과 웹을 언급해 플랫폼 목록이 일치하지 않는다. 원고는 Meta의 목록을 "Meta lists"로 표시했다.
- "민감한 행동"의 범위는 Meta 공식 글이 예시 두 가지(이메일 발송, 구매)만 들고 전체 목록은 정하지 않았다. 이 확인은 페이지 읽기 도구가 인용해 준 구절에 근거한 것이며, 공식 글 전체를 처음부터 끝까지 직접 읽은 것은 아니다.
- 읽은 페이지는 모두 읽기 도구를 거친 요약이다.

## 2. 도식

- 직접 만든 도식 1개(960×400): 카드 세 장 "What can it reach?" / "If it is wrong?" / "Can you undo it?". 하단 문구는 "Original diagram. No logos or product images."
- 로고·제품 사진·스크린샷 없이 만들었다. 사용자가 승인했다.
- 도식 파일(SVG)은 이 저장소에 넣지 않았다.
